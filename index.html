Por defecto, la app guarda los datos en tu navegador (Modo Local). Compartir información con los compañeros del turno de mañana y tarde, pega aquí la URL de una base de datos gratuita de Firebase Realtime Database que te comparte el administrador:

¿URL gratuita FIREBASE?
  1. Generada con cuenta Google console.firebase.google.com (ej. parking-cc).
  2. En el menú izquierdo Compilación → Realtime Database y haz clic en Crear base de datos.

Publicar en tu cuenta de GitHub

Alojamiento gratuito 24/7 con enlace web para compartir por WhatsApp/Teams

  1. Inicia sesión en tu cuenta de GitHub y crea un repositorio nuevo llamado control-parking-cc (público).
  2. Sube este único archivo con el nombre exacto index.html (puedes usar el botón "Add file → Upload files" o copiar el código directamente).
  3. Ve a la pestaña Settings (Configuración) del repositorio y en el menú lateral selecciona Pages.
  4. En "Build and deployment → Branch" elige main y carpeta / (root), luego pulsa Save.
  5. GitHub se entrega enlace público para uso de la aplicación listo para abrir desde cualquier celular o su laptop.
